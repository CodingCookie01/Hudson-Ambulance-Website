# Hudson Ambulance Website

A modern static website for Hudson Ambulance designed for GitHub Pages.

## Files included
- index.html
- fundraisers.html
- staff.html
- history.html
- contact.html
- donate.html
- assets/css/styles.css
- assets/js/site.js

## Publish on GitHub Pages
1. Push these files to the GitHub repository.
2. Go to repository Settings > Pages.
3. Under "Source", choose "Deploy from a branch".
4. Select the `main` branch and the root folder.
5. Save.

Your site will be published at:
https://<username>.github.io/<repo-name>

## Donation integration
The donate page currently has placeholder buttons. Replace those with real PayPal or Stripe links when ready.

## Edit content
- Update fundraiser info in `assets/js/site.js` under `fundraisers`
- Update staff info in `assets/js/site.js` under `staff`
- Update history in `assets/js/site.js` under `historyMilestones`
